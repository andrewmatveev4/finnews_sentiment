# День 4. Улучшение baseline

## Протокол
- Выбор модели только по 5-fold стратифицированной кросс-валидации на train (3868), метрика macro F1.
  Фолды одинаковые для всех экспериментов.
- Test (967) открыт один раз, для финальной модели.
- Каждый эксперимент меняет одну вещь относительно baseline. Комбинация отдельно.

## Результаты кросс-валидации

| Эксперимент | Что изменено | CV macro F1 | Против baseline |
|---|---|---|---|
| baseline | TF-IDF (1,2), 5000 признаков + LogReg C=1 | 0.6522 ± 0.013 | - |
| E1_class_weight | class_weight="balanced" | 0.7151 ± 0.018 | **+0.063** |
| E2_token_pattern | токены из 1 символа и `%` | 0.6459 ± 0.010 | -0.006 (шум) |
| E3_trigrams | ngram_range=(1, 3) | 0.6504 ± 0.011 | -0.002 (шум) |
| E4_linear_svc | LinearSVC вместо LogReg | 0.7062 ± 0.022 | +0.054 |
| E5_tuned_C10 | C=10 | 0.6971 ± 0.025 | +0.045 |
| **E6_C3_balanced** | C=3 + class_weight="balanced" (GridSearchCV по f1_macro) | **0.7211 ± 0.013** | **+0.069** |

## Финал на test (один прогон)

| | Baseline | E6 |
|---|---|---|
| macro F1 | 0.6925 | **0.7269** |
| accuracy | 0.776 | 0.769 |
| negative recall | 0.438 | 0.686 |
| negative precision | 0.841 | 0.648 |

Прирост на test +4.97% относительно (планка +5% = 0.7271, не хватило 0.0002, что меньше одного примера
и намного меньше шума test-оценки ±0.02). По CV прирост +10.6%. Подстройка по test не проводилась.
Планка +5 процентных пунктов (0.7425) не достигнута.

## Что помогло и почему
- **class_weight="balanced"**: главный вклад. Без весов модели выгодно отвечать neutral на всё сомнительное;
  с весами пропуск редкого класса дорог, recall negative 0.44 -> 0.69.
- **Подбор C**: baseline был пережат регуляризацией (без весов C=1 -> 0.652, C=10 -> 0.697).
  С весами эффект C мал (+0.006 к E1, в пределах шума).
- **LinearSVC** выиграл у baseline из-за более слабой эффективной регуляризации, а не за счёт модели:
  LogReg с подобранным C его догоняет.

## Что не помогло и почему
- **Однобуквенные токены и `%`**: числа не несут направления (`45` есть и в rose, и в fell),
  а частый мусор (`s`, `a`) вытеснил полезные признаки из лимита 5000.
- **Триграммы**: редкие, почти не проходят лимит 5000; отрицания уже ловят биграммы.

## Выбор
E6 (LogReg, C=3, balanced): лучший по CV, сбалансированные precision/recall по классам,
и в отличие от LinearSVC умеет predict_proba (нужно для inference на Дне 6).
